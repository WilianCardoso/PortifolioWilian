# Portfólio — Wilian Cardoso

Site pessoal responsivo feito com HTML, CSS e JavaScript, pronto para hospedar no GitHub Pages.

## Executar localmente
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `portfolio`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
4. O endereço esperado será `https://WilianCardoso.github.io/portfolio/` após a publicação.
